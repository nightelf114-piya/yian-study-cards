閱讀器設定

內建的 303 張圖卡可以快取離線閱讀。你新增或替換的圖片會保存在本機圖片資料庫（同一支手機、同一個網站）；不會寫入伺服器 images 資料夾。

完整圖片備份（建議定期匯出）

將新增圖片、替換圖片、隱藏設定和學習紀錄一起匯出成 ZIP。換手機時可用 ZIP 還原；原本 303 張內建圖卡仍由網站提供。

備份學習紀錄

收藏與已讀進度儲存在手機瀏覽器；更換手機或清除網站資料可能遺失，可以先匯出備份。

新增與刪除只影響本機資料；清除網站資料、換手機、移除 App 或瀏覽器回收空間都可能讓自訂圖片消失。內建圖片的「刪除」是隱藏，可隨時還原；匯出備份 ZIP 比只備份進度 JSON 更完整。

iPhone／Android 請先將這個網站放在 HTTPS 網址，再透過瀏覽器的「加入主畫面／安裝」功能使用；直接打開本機 HTML 不能保證有離線快取與安裝功能。

圖片管理

可一次新增多張 PNG、JPG 或 WebP。內建 303 張可「隱藏」或「替換」，不會真的刪除網站原圖；自己新增的圖片可永久刪除。

新增圖片只存在這支裝置的瀏覽器資料庫，網站管理員與其他手機不會自動看到。請使用「設定 → 匯出完整備份 ZIP」備份。
