乙安故事記憶圖｜手機閱讀器 v2（可新增、替換、隱藏、刪除圖片）
==========================================================

檔案結構
- index.html：網站首頁
- data.js、supplement.js：303 張內建圖卡的標題與檔名
- app.js：閱讀／圖片管理程式
- image-library.js：本機 IndexedDB 圖片資料庫
- zip-store.js：自訂圖片的 ZIP 備份／還原
- styles.css：畫面樣式
- images/：原本內建 303 張大圖
- thumbs/：原本內建 303 張縮圖
- sw.js：網站離線快取

網站部署
1. 解壓縮整個 ZIP，不要只上傳 index.html。
2. 將本資料夾的全部檔案、images 及 thumbs 一起部署到 HTTPS 靜態網站。
   如果原本就部署了第一版，請直接在「相同網址／相同網站路徑」更新檔案。
3. 手機用 Safari（iOS）或 Chrome（Android）開網站，加入主畫面／安裝網站 App。
4. 若網站顯示舊版，重新整理後完全關閉再開；必要時等待新版 Service Worker 啟用。
5. 首頁點「法規補充」，可集中查看第 196 至 303 張；首頁和閱讀畫面也能直接跳到指定編號。

增加圖片（在閱讀器裡直接操作）
1. 在首頁點「＋ 新增圖片」。
2. 可以一次選取多張 PNG、JPG、WebP、GIF 或 AVIF（單張小於 60 MB）。
3. 閱讀器會自動產生縮圖並分配 304、305、306… 編號。
4. 新圖儲存在同一支手機的瀏覽器／PWA IndexedDB 資料庫，能離線閱讀。
5. 點「管理／刪除圖片」可重新命名、替換圖片或刪除自訂圖卡。

替換既有內建圖片
1. 點「管理／刪除圖片」，搜尋編號，例如 001。
2. 按「替換圖片」，選取新版圖片；標題及閱讀紀錄維持不變。
3. 若要回到原本圖片，按「還原原圖」。
注意：替換圖片不會直接改動 images/001.webp，而是本裝置的覆蓋版本。

刪除／隱藏圖片
- 原本 303 張內建圖卡：只能「隱藏」，不會從網站刪除；可以隨時按「顯示回目錄」。
- 自己新增的圖卡：按「刪除圖片」會真正從本裝置資料庫刪除，操作會二次確認。
- 其他裝置上的圖片或網站伺服器資料不會因此被刪除。

完整備份（非常重要）
1. 開啟右上角「⚙ 設定」。
2. 按「匯出完整備份 ZIP」，會包含所有自行新增／替換的圖片、隱藏設定、已讀及收藏紀錄。
3. 把 ZIP 存到手機檔案或雲端硬碟；更換手機時，開啟閱讀器網站後按「匯入完整備份 ZIP」。新版也可匯入舊版 195 張的備份，若自訂圖卡編號重疊，系統會重新編號。
4. 匯入會覆蓋目前手機的本機自訂圖片與學習進度，請先自行備份重要資料。
5. 原始內建 303 張圖本來就包含在完整網站包中，沒有重複放到自訂 ZIP 備份。

重要限制
- 瀏覽器網頁無法直接寫入或刪除伺服器上的 images 資料夾。
- 本機新增圖片不會自動同步到雲端、其他手機或其他瀏覽器。
- 清除網站資料、換手機、移除 PWA，或瀏覽器回收儲存空間可能刪除本機圖片。
- 若要讓所有手機共用同一套新圖，仍須由管理者在伺服器更新 images、thumbs 及對應的圖卡清單，或增加具有帳號及雲端同步的後端。
- 自訂圖片的資料庫離線可用；內建 303 張的離線閱讀，需先在線上使用「設定 → 儲存內建圖卡供離線使用」。
- 圖卡為 PDF 教材故事化整理，不代表 2026 年現行法規皆已完成逐條校對。
